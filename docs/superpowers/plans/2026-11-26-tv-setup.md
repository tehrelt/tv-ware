# tv-setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Построить десктопное Windows-приложение `tv-setup` на Python + CustomTkinter для автопоиска Android TV в сети/по USB, загрузки актуальных APK из GitHub Releases, установки `tv-launcher` и `Happ`, безопасного debloat и ускорения анимаций с полным откатом, а также CI-сборку `tv-launcher.apk` в GitHub Actions.

**Architecture:** Модульный Python-пакет `tv-setup/tv_setup/` разделён на независимые слои без привязки к GUI: `adb_client` (поиск/скачивание `platform-tools` и обёртка `subprocess`), `discovery` (USB + `zeroconf` mDNS + скан `/24` порта `5555`), `presets` + `optimizer` (инспекция ТВ, снимок состояния в JSON, твики и откат), `installer` (GitHub Releases API + локальные APK + установка и смена `HOME`) и `gui` (графитовое окно CustomTkinter с фоновыми потоками). Отдельный workflow `.github/workflows/release-launcher.yml` публикует `tv-launcher.apk` в rolling-релиз `launcher-latest`.

**Tech Stack:** Python 3.12, CustomTkinter (`>=5.2.2,<7.0`), `zeroconf` (`>=0.132.0`), `unittest` + `unittest.mock`, GitHub Actions (`ubuntu-latest`, JDK 21, Gradle 8.14.3).

**Spec:** `docs/superpowers/specs/2026-11-25-tv-setup-design.md`

## Global Constraints

- Целевая ОС: Windows 11, Python 3.12.10; все вызовы `subprocess.run` на Windows используют `CREATE_NO_WINDOW` и явные таймауты.
- Зависимости строго минимальны: `customtkinter>=5.2.2,<7.0` и `zeroconf>=0.132.0`; остальное — стандартная библиотека Python.
- Запросы к GitHub API идут без авторизации к публичным репозиториям `tehrelt/tv-ware` (`releases/tags/launcher-latest`, ассет `tv-launcher.apk`) и `Happ-proxy/happ-android` (`releases/latest`, ассет `Happ.apk`).
- Палитра GUI повторяет `tv-launcher`: фон `#0A0A0B`, карточки `#1C1C1E`, элементы `#2C2C2E`, текст `#F5F5F7` / `#A1A1A6`, акцент `#0A84FF`, успех `#4CC38A`.
- Артефакты среды (`tv-setup/.venv/`, `tv-setup/tools/`, `tv-setup/apks/`, `tv-setup/state/`, `__pycache__/`, `*.pyc`) исключены из git через `.gitignore`.
- Пакет лаунчера: `com.tvware.launcher`, activity: `com.tvware.launcher/.MainActivity`; пакет Happ: `su.happ.proxyutility` (fallback `com.happproxy`).

## Review Focus

- **Zip-slip и битый архив `platform-tools`:** путь вида `../evil.exe` или абсолютный путь внутри zip должен вызывать `ValueError` и не писать за пределы `tv-setup/tools/` (проверяется в Task 2).
- **Виртуальные и link-local интерфейсы при скане сети:** адаптеры `vEthernet`, `Meta` (`198.18.0.1/30`), `169.254.x.x`, `127.0.0.1` должны отбрасываться, а реальные LAN/Wi-Fi интерфейсы нормализоваться в `/24` (проверяется в Task 3).
- **Дедупликация mDNS + порт `5555` + USB и статус сопряжения:** один и тот же IP из нескольких источников должен сливаться в одну запись с приоритетом `CONNECTED` > `READY` > `NEEDS_PAIRING` > `DEBUG_OFF` без потери `pairing_port` (проверяется в Task 3).
- **Защита стокового лаунчера и сохранность исходного снимка:** отключение стокового `HOME` запрещено, если `com.tvware.launcher` не установлен; повторный запуск не перезаписывает исходные `home_component` и `animation_scales` в `state/<device_id>.json` (проверяется в Task 4).
- **Rolling-релиз `launcher-latest` и конфликт подписи APK:** обновление `tv-launcher.apk` определяется по `(asset_id, updated_at)` в `.versions.json`, а `INSTALL_FAILED_UPDATE_INCOMPATIBLE` поднимает `SignatureConflictError` вместо молчаливого удаления данных (проверяется в Task 5).

import tempfile
import unittest
import zipfile
from pathlib import Path
from unittest.mock import patch

from tv_setup.adb_client import (
    AdbClient,
    find_adb_executable,
    parse_adb_devices,
    safe_extract_zip,
)


class AdbClientTests(unittest.TestCase):
    def test_find_adb_prefers_local_tools_then_path_then_sdk(self):
        with tempfile.TemporaryDirectory() as tmp:
            root = Path(tmp)
            local_adb = root / "tools" / "platform-tools" / "adb.exe"
            local_adb.parent.mkdir(parents=True)
            local_adb.write_bytes(b"adb")
            found = find_adb_executable(root / "tools", which_fn=lambda _: "C:/other/adb.exe")
            self.assertEqual(found, local_adb)

            local_adb.unlink()
            sdk_adb = root / "appdata" / "Android" / "Sdk" / "platform-tools" / "adb.exe"
            sdk_adb.parent.mkdir(parents=True)
            sdk_adb.write_bytes(b"adb")
            self.assertEqual(
                find_adb_executable(root / "tools", which_fn=lambda _: None, local_appdata=str(root / "appdata")),
                sdk_adb,
            )

    def test_safe_extract_zip_rejects_zip_slip(self):
        with tempfile.TemporaryDirectory() as tmp:
            root = Path(tmp)
            bad_zip = root / "bad.zip"
            with zipfile.ZipFile(bad_zip, "w") as zf:
                zf.writestr("../evil.txt", "boom")
            with self.assertRaises(ValueError):
                safe_extract_zip(bad_zip, root / "out")
            self.assertFalse((root / "evil.txt").exists())

    def test_parse_adb_devices_extracts_usb_and_tcp(self):
        raw = (
            "List of devices attached\n"
            "192.168.31.42:5555     device product:jaws model:MiTV_AFKR0 device:jaws transport_id:2\n"
            "ABC12345               unauthorized usb:1-2 transport_id:3\n"
        )
        devices = parse_adb_devices(raw)
        self.assertEqual(len(devices), 2)
        self.assertEqual(devices[0].serial, "192.168.31.42:5555")
        self.assertEqual(devices[0].model, "MiTV_AFKR0")
        self.assertEqual(devices[1].state, "unauthorized")

    def test_connect_parses_already_connected_and_failure(self):
        client = AdbClient(adb_path=Path("adb.exe"))
        with patch.object(client, "run") as mock_run:
            mock_run.return_value = type("R", (), {"returncode": 0, "stdout": "connected to 192.168.31.42:5555", "stderr": ""})()
            ok, msg = client.connect("192.168.31.42:5555")
            self.assertTrue(ok)
            self.assertIn("connected", msg)

            mock_run.return_value = type("R", (), {"returncode": 0, "stdout": "cannot connect to 192.168.31.42:5555: Connection refused", "stderr": ""})()
            ok, _ = client.connect("192.168.31.42:5555")
            self.assertFalse(ok)
```

import ipaddress
import unittest

from tv_setup.adb_client import UsbOrTcpDevice
from tv_setup.discovery import (
    DeviceStatus,
    MdnsRecord,
    extract_scan_subnets,
    is_virtual_interface,
    merge_discovered_devices,
)


class DiscoveryTests(unittest.TestCase):
    def test_filters_virtual_and_link_local_interfaces(self):
        interfaces = [
            ("vEthernet (Default Switch)", "172.29.128.1", 20),
            ("Meta", "198.18.0.1", 30),
            ("Подключение по локальной сети* 10", "169.254.9.69", 16),
            ("Беспроводная сеть", "192.168.31.73", 24),
            ("Loopback Pseudo-Interface 1", "127.0.0.1", 8),
        ]
        self.assertTrue(is_virtual_interface("vEthernet (Default Switch)"))
        self.assertTrue(is_virtual_interface("Meta"))
        self.assertFalse(is_virtual_interface("Беспроводная сеть"))
        subnets = extract_scan_subnets(interfaces)
        self.assertEqual(subnets, [ipaddress.IPv4Network("192.168.31.0/24")])

    def test_merges_mdns_and_port_5555_with_priority_and_pairing_port(self):
        mdns = [
            MdnsRecord("_androidtvremote2._tcp.local.", "MiTV-AFKR0", "192.168.31.42", 6466),
            MdnsRecord("_adb-tls-pairing._tcp.local.", "adb-pair", "192.168.31.50", 37123),
            MdnsRecord("_adb-tls-connect._tcp.local.", "adb-tls", "192.168.31.50", 41234),
            MdnsRecord("_androidtvremote2._tcp.local.", "LivingRoomTV", "192.168.31.60", 6466),
        ]
        usb = [
            UsbOrTcpDevice("192.168.31.42:5555", "device", "MiTV_AFKR0", "jaws", "1"),
        ]
        merged = merge_discovered_devices(usb, mdns, open_5555_ips=["192.168.31.42", "192.168.31.77"])
        by_ip = {d.ip: d for d in merged}

        self.assertEqual(by_ip["192.168.31.42"].status, DeviceStatus.CONNECTED)
        self.assertEqual(by_ip["192.168.31.42"].port, 5555)
        self.assertEqual(by_ip["192.168.31.50"].status, DeviceStatus.READY)
        self.assertEqual(by_ip["192.168.31.50"].port, 41234)
        self.assertEqual(by_ip["192.168.31.50"].pairing_port, 37123)
        self.assertEqual(by_ip["192.168.31.60"].status, DeviceStatus.DEBUG_OFF)
        self.assertEqual(by_ip["192.168.31.77"].status, DeviceStatus.READY)
        self.assertEqual(by_ip["192.168.31.77"].port, 5555)

    def test_pairing_only_device_gets_needs_pairing_status(self):
        mdns = [MdnsRecord("_adb-tls-pairing._tcp.local.", "MiBox", "192.168.31.88", 39999)]
        merged = merge_discovered_devices([], mdns, open_5555_ips=[])
        self.assertEqual(len(merged), 1)
        self.assertEqual(merged[0].status, DeviceStatus.NEEDS_PAIRING)
        self.assertEqual(merged[0].pairing_port, 39999)
```

                return res
        return AdbResult(0, "Success", "")
